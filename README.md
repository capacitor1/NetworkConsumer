# NetworkConsumer
网络流量消耗器，又名 ~~运营商高兴器~~

> 此为新版构建，使用WinUI3框架，并优化了旧版中一些逻辑不恰当的代码，但因为WinUI3编译导致程序体积大，故旧版软件的代码仍保留。

可用于：

- 刷下载流量以应对国内运营商PCDN政策（在大量上传后平衡下载）

- 快速消耗完按月计费、固定流量的流量套餐（消耗VPN流量需自行添加符合VPN Proxy规则的URL，项目自带的URLs只包含中国大陆服务器）

- 在安装高带宽网络之后对自己带宽或不同服务器的实际速度进行测试（已知部分服务器给软件安装包提供的带宽不能跑满1000Mbps及以上家庭宽带）

- 为自己的VPS云服务器或者个人下载站这种私有站进行速度和稳定性测试（注意别把VPS流量搞没了）

## 使用方法和UI说明

- 新版：

<img width="648" height="202" alt="{F257D22F-936F-4726-8A46-35D1C2B19C81}" src="https://github.com/user-attachments/assets/32b8e8a5-0550-4439-b34c-1dfa7e34b59b" />

新版UI中，左上角为速度指示，右侧上为消耗总流量计数，下为当前线程数指示。在下拉菜单中选择URL（基于URLs.txt），如遇空行则不能启动。

鼠标左键线程数指示，可增加线程数（文本会显示`Set -> X T`，X为预设线程数），鼠标右键减少。每点击一次，数值只上升/下降1。鼠标中间重置为初始值1。

然后在操作面板中开始或结束流量消耗。

- 旧版：

<img width="661" height="208" alt="{36997F01-B26A-4E7F-911A-4E90355FF578}" src="https://github.com/user-attachments/assets/49969a0c-2372-4cc3-bc72-93ebaa4c8beb" />

需要在启动前，手动放置URLs.txt文本文档，存入URL，每行一个，不支持空行。

然后在操作面板中开始或结束流量消耗。

> 软件会创建Total.bin用于存储流量消耗累计值，这个文件新旧版通用。但需注意：**不能同时运行两个流量消耗器，读写这个文件会冲突**

两个版本的区别：

||旧版|新版|
|:-:|:-:|:-:|
|URL行为|选择空行并启动会卡死|空URL则无法启动流量消耗|
|流量消耗累计值保存|正常|较频繁|
|URL错误处理|立即重试|500ms重试|
|软件本身|需要.NET依赖库|独立软件|

## 关于 `URLs.txt`

可手动修改，只支持每行一个、不空行的http/https URL。支持v4/v6访问。

在有VPN软件存在时，VPN规则可能会代理部分URL，故手动添加URL时注意这一点，避免VPN节点流量意外消耗。

内容安全性声明：项目自带一个URLs文本，其中的URL均从网络搜索并收集，只包含互联网大厂的URL，不涉及任何个人网站、用户隐私文件或病毒URL。
